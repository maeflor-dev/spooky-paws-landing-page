# Spooky Paws Grooming Studio

A cinematic Halloween-themed landing page for a fictional pet grooming studio. Built with plain HTML, CSS, and JavaScript, with no frameworks or build tools.

> **DEMO VERSION.** This is a template for portfolio/demo purposes. The studio, team members, and prices are fictional.

## Project Structure

```
spooky-paws/
├── index.html   # Page markup (all sections)
├── styles.css   # All styling, design tokens, and responsive rules
├── script.js    # All interactivity
└── README.md    # This file
```

## How to Run

1. Keep all files in the **same folder**.
2. Open `index.html` in any modern browser (double-click it).

No installation or server is required. An internet connection is needed to load the fonts, icons, and photos.


## Page Sections

| Section | Anchor ID |
|---|---|
| Home | `#home` |
| About | `#about` |
| Team | `#team` |
| Pricing | `#services` |
| Gallery | `#gallery` |
| Booking | `#booking` |

## Tech Used

- HTML5, CSS3 (custom properties, Grid, Flexbox, `clamp()`), and vanilla JavaScript (ES6)
- [Google Fonts](https://fonts.google.com): Cinzel Decorative, Creepster, Plus Jakarta Sans
- [Font Awesome 6.4](https://fontawesome.com) for icons

## Notes

- The booking form is a front-end demo only. It shows a confirmation message but does not send or store data. Connect it to a backend (for example PHP/MySQL) to save real appointments.
- Photos come from [Unsplash](https://unsplash.com) and are for demo purposes. Check the license and credit requirements before using them in a live site.
